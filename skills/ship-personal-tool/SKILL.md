# Ship a personal tool

- Default stack: Next.js + TypeScript.
- When visual fidelity is the priority, port the existing CSS and rendering close to verbatim. No Tailwind rewrite.
- Process sensitive user data in the browser (Web Worker), and say so in the UI.
